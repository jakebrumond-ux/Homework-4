Welford’s Recurrences and Sampling Statistics

Exercise 1 – Welford’s Recurrence Formulas

/*  DERIVATION
    M_k  = mean of the first k values,   SS_k = sum_{i=1..k} (x_i - M_k)^2
    Knuth:  M_k = M_{k-1} + (x_k - M_{k-1}) / k
    Let d = x_k - M_{k-1}, so M_k = M_{k-1} + d/k.

    Use  SS_k = sum(x_i^2) - k*M_k^2.  Then
      SS_k - SS_{k-1} = x_k^2 - k*M_k^2 + (k-1)*M_{k-1}^2

    Expand  k*M_k^2 = k*M_{k-1}^2 + 2*M_{k-1}*d + d^2/k, so
      SS_k - SS_{k-1} = x_k^2 - M_{k-1}^2 - 2*M_{k-1}*d - d^2/k

    Since x_k^2 - M_{k-1}^2 = d*(d + 2*M_{k-1}) = d^2 + 2*M_{k-1}*d :
      SS_k - SS_{k-1} = d^2 - d^2/k = d^2 * (k-1)/k

    Also x_k - M_k = d - d/k = d*(k-1)/k, hence

      SS_k = SS_{k-1} + d * (x_k - M_k)              (M_0 = SS_0 = 0)

    Variance (unbiased) s2_k = SS_k / (k-1), which obeys
      s2_k = ((k-2)/(k-1)) * s2_{k-1} + d^2 / k       for k >= 2
    Population version: SS_k / k.
*/

function welford(xs) {
  let M = 0, SS = 0, k = 0;
  for (const x of xs) {
    k++;
    const d = x - M;        // d = x_k - M_{k-1}
    M  += d / k;            // Knuth's mean update
    SS += d * (x - M);      // Welford's SS update
  }
  return [M, SS / (k - 1)]; // sample mean, unbiased sample variance
}

Exercise 2 – Sampling Mean and Variance

// Scores ~ discrete uniform on {0, 1, ..., 10}
// mu     = 5
// sigma2 = (11^2 - 1) / 12 = 10
// mu4    = 178   (fourth central moment)
//
// m hackers, each attacking n systems -> a trajectory of n scores.
// Per hacker: Welford gives (sample mean, sample variance).
// Across hackers: average the means and the variances, compare to mu, sigma2.

const MU = 5, SIGMA2 = 10, MU4 = 178;

function mulberry32(a) {            // small seeded RNG
  return () => {
    a |= 0; a = a + 0x6D2B79F5 | 0;
    let t = Math.imul(a ^ a >>> 15, 1 | a);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}

function experiment(n, m, rand) {
  const means = [], vars = [];
  for (let h = 0; h < m; h++) {
    let M = 0, SS = 0;                              // inline Welford
    for (let k = 1; k <= n; k++) {
      const x = Math.floor(rand() * 11);            // score in 0..10
      const d = x - M; M += d / k; SS += d * (x - M);
    }
    means.push(M); vars.push(SS / (n - 1));
  }
  const avg = a => a.reduce((s, v) => s + v, 0) / a.length;
  const sd  = a => { const mu = avg(a); return Math.sqrt(avg(a.map(v => (v - mu) ** 2))); };
  return {
    n, avgMean: avg(means), avgVar: avg(vars), sdMean: sd(means), sdVar: sd(vars),
    thMean: Math.sqrt(SIGMA2 / n),                                  // sigma / sqrt(n)
    thVar:  Math.sqrt((MU4 - SIGMA2 ** 2 * (n - 3) / (n - 1)) / n)  // sqrt(Var(s2))
  };
}

Conclusions

/*
1. Both estimators are unbiased: E[sample mean] = mu, E[sample variance] = sigma2.
   The average over hackers approaches mu = 5 and sigma2 = 10 for every n, even n = 5.
   This relies on dividing by n-1 (Bessel's correction); dividing by n would give
   sigma2 * (n-1)/n on average, which is visibly too low for small n.

2. Inference: mu and sigma2 are normally unknown. This result justifies using the
   sample mean and variance of ONE trajectory as estimates of them. Each hacker is
   one possible sample whose statistics scatter around the truth with no systematic
   error. This underlies confidence intervals, t-tests and the standard error s/sqrt(n).

3. Effect of n:
   - Var(sample mean) = sigma2 / n          -> spread shrinks like 1/sqrt(n)
   - Var(sample var)  = (mu4 - sigma2^2 * (n-3)/(n-1)) / n  -> also order 1/n
   Both estimators are consistent. Variance estimates are noisier than mean
   estimates at the same n because the constant depends on the fourth moment.
   By the CLT the sample mean also becomes approximately normal as n grows.

4. m vs n: increasing m only sharpens the average over hackers (the estimator's
   expectation, already correct). Increasing n improves each individual estimate.

5. Why Welford: one pass, O(1) memory, and no catastrophic cancellation as in the
   naive sum(x^2) - n*mean^2 formula.
*/
